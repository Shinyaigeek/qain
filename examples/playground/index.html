qain playground

Edit either page. qain captures the browser's used values — resolved computed styles, layout boxes, paint order, composited colours — from both, and diffs them semantically: what changed, and what merely moved. Every change is attributed to the CSS declaration behind it. All of it runs in this tab — no server, no CDP.
