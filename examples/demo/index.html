qain — live demo

qain is style-regression testing that reports what changed and what merely moved — the browser's resolved computed styles, diffed semantically, with each change attributed to the CSS declaration that caused it.

Everything on this page is generated by CI from the example billing page and a stylesheet that breaks it four ways at once: a reflow, a WCAG contrast regression, a stacking-order change, and a :hover state that stopped differing — plus a utility-class rehash that must produce no diff at all.

  • Interactive replay diff — both pages rebuilt pixel-exactly from the snapshots; fade one into the other, causes outlined in red. (qain diff --replay)
  • HTML report — every change, its cause, and the file:line behind it. (qain diff --html)
  • Terminal output — what CI and coding agents read. Exit code 1 when non-empty.
  • before.json / after.json — the raw snapshots: every element's resolved computed styles, layout box, paint order, and matched CSS rules, as plain JSON.

Run it on any URL a browser can open:

npx playwright install chromium   # once
npx @qain/cli snap https://example.com --rules -o page.json
